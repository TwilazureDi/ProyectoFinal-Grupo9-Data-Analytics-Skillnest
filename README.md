# Skillnest - Data Analytics Argentina

Actividad Grupal del programa de Data Analytics de Skillnest enfocado en la organizacion, limpieza, analisis comercial y visualizacion de una base de datos utilizando las herramientas mostradas en el programa como: 
- Python y las librerias Pandas, Matplotlib, Seaborn, KMeans y StandardScaler
- gestion de consultas de SQL mediante sqlite3
- Power BI
